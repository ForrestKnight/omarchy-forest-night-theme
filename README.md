# Forest Night — Omarchy theme

A dark theme for [Omarchy](https://omarchy.org) built on the
[Forest Night — Ethereal](https://marketplace.visualstudio.com/items?itemName=forrest-knight.forest-night-theme)
VS Code theme: a deep blue-slate background with muted forest green, teal,
purple and amber accents.

![Forest Night preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/ForrestKnight/omarchy-forest-night-theme.git
```

Or from the desktop: `Super + Alt + Space` → Install → Style → Theme, then paste the URL above.

The theme then shows up as **Forest Night** in the theme switcher.
